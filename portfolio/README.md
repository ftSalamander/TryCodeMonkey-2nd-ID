# Araf Portfolio

Personal portfolio of Araf. Frontend-only, built with Angular and Bootstrap. Colorful, high-contrast, fully responsive.

## Sections

- Hero
- About
- Skills matrix
- Projects showcase
- Contact form (static, no backend)

## Run locally

```bash
cd portfolio
npm install --legacy-peer-deps
npm start
```

Then open `http://localhost:4200`.

## Preview notes

- The dev server binds to `0.0.0.0` and allows `*.monkeycode-ai.live` hosts.
- Images use `https://via.placeholder.com/...` so you can swap them later.
- Skills and projects live in `src/app/data/portfolio.data.ts`.
